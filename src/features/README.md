# Features

Các nhóm chức năng (feature modules) của ứng dụng.

| Feature | Mô tả | Modules con |
|--------|--------|-------------|
| **Identity** | Xác thực & phân quyền | Auth, Users, Roles, Permissions |
| **Catalog** | Danh mục & dịch vụ | Categories, Services, Combos, Materials |
| **Booking** | Đặt lịch & thanh toán | Appointments, Payments, Reviews |
| **Messaging** | Hội thoại | Conversations, Messages |
| **Staff** | Ca làm & nghỉ | StaffSchedule, StaffDayOff, WorkingHour |
| **Notifications** | Thông báo | Notifications |
